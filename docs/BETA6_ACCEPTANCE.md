# beta.6 安装与历史容量验收

更新：2026-10-27，beta.6。下列人工步骤供用户设备执行，不能代替实际安装验收。

两台Windows下载同一版本，核对`SHA256SUMS.txt`，保存退出、保留完整小说及创作资料备份后安装。不要先卸载旧版或删除历史，模型配置分别管理；[安装保护](INSTALLER_SAFETY.md)和[两机接力](SECOND_WINDOWS_ACCEPTANCE.md)适用。

## 容量界面

1. 打开一份独立的虚构测试小说，进入“固定资料同步…”→“历史版本与原稿保护”→“浏览历史与找回资料”。
2. 顶部应单独显示本机替换前归档、书内传输目录的条目数、剩余名额和核对时间。无历史时显示0，统计不会启用同步或创建历史目录。
3. 点击“刷新历史列表”同时刷新容量；另一部同名小说应独立显示。统计包含未完成传输目录，不等于已核验版本数或磁盘字节。
4. 已有合法历史时，仍可预览差异、恢复为新副本或打包历史ZIP。原历史、正式资料和同步基线不改变，未确认草稿不自动成为正史。

800预警、1,000满额、1,001超限、写前拒绝及外部交错由临时目录自动化覆盖，无需在用户小说里人为制造1,000个目录。归档ZIP不会释放名额；不要删除父版本来绕过限制。完整DAG批量归档/清理仍未实现。

开发阶段884核心、118相关核心、6套桌面通过；升beta.6后类型/构建及34项打包保护核心通过。真实ASAR容量UI覆盖800→1,000→1,001、独立错误/错书/延迟、满额副本/ZIP和重开；隔离复制beta.1→beta.6升级模拟通过。安装器实际payload和包内7个out部件与构建一致；src/out/实际asar/resources隐私规则无发现。
