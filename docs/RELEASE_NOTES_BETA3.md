# 小说编写器 0.1.1 Beta 3

Windows x64 测试版，安装包尚未签名。两台电脑请使用同一版本；升级前先在旧版保存并退出，保留整书备份，不要先卸载旧版或删除安装目录旁的“创作资料”。

## 本版改动

- **资料历史找回**：浏览本机替换前归档及书内旧版本、并行版本，逐文件对照当前与历史内容。可恢复整个历史版本为独立新副本，保留当前设定、同步基线及历史原件；未确认草稿不会自动成为正史。
- **历史ZIP留档**：将单个已核验版本压缩为ZIP，提供路径、大小及SHA-256，并在最终复核后写完成清单。旧历史继续保留；这不是批量清理，也不会删除父版本来绕过数量上限。
- **Word结构副本编辑**：在保真副本窗口进入“表格与页眉页脚…”，编辑简单平面表格的单元格文字、增删行，以及已有页眉页脚文字。多项操作统一另存一份新DOCX；复杂合并、嵌套、域或修订结构只读说明。
- **Word图片替换**：在同一窗口进入“替换已有图片…”，选择已有PNG/JPEG部件，通过原生文件选择器选择图片，按目标格式转换后另存新DOCX。原稿、现有布局引用及未改部件保留；不插入新图片或读取外部链接图片。
- **保存保护修复**：修正结构副本保存退出被退出锁拦截、表格界面上限与后端不一致，以及XML注释/处理指令里的伪标签被误读成正文的问题。图片增加解码前的容器、尺寸与像素上限检查，解码后再次核对。

正文仍默认DOCX、宋体五号10.5磅，段首为两个可复制的真实全角空格。人物、世界观等Markdown资料仍按小说ID隔离；所有副本和AI请求绑定原小说及来源版本。

## 同步、升级与隐私

正式资料位于本机应用数据目录，Windows默认 `%APPDATA%\novel-writer\创作资料\<projectId>\`。沿用升级前完整校验备份和安全迁移保护；发现冲突、损坏或旧应用仍在运行时停止，不强杀写作进程或覆盖不同资料。

固定资料随书同步需要完整传输小说目录，包含“小说资料/创作资料同步”。外部NAS/网盘客户端负责传输，应用不能确认服务商云端进度。密钥、模型连接、本机任务、用量及索引不随小说复制；请勿复制整个AppData来接力写作。

发布内容不包含作者的NAS地址、账号、API密钥、小说或私人开发日志。模型连接和远端目录由每位使用者独立配置。
