# 小说编写器 0.1.1 Beta 7

Windows x64测试版。本版加入完整资料历史的整体归档与校验导入为新副本，既有beta.6和更早附件保留。

## 本版改动

- **完整历史归档**：核对本书所有已完成传输版本、完整父链和并行分支，以及本机替换前归档；原始清单和文件字节按SHA-256去重，生成独立ZIP和完成清单。遇到未完成上传、缺父、损坏、来源变化或嵌套空目录时停止，避免生成不完整的成功包。
- **导入为新副本**：选择完整历史ZIP及同目录完成清单，逐项核对小说归属、ZIP结构、对象哈希、路径、版本和父链，再在本书目录生成独立副本。预览票据有效15分钟；导入不合并原同步历史、不换入正式资料，也不会自动确认草稿。
- **历史与当前资料保护**：预览和写入时重新核对来源、当前资料、书籍身份及目标；文件在读取期间被改写会拒绝。ZIP留档不删除父版本，也不会释放历史目录名额；完整世代清理／容量回收尚未实现。
- **网盘状态**：应用内 NAS／网盘账户直连暂未开放。普通文件夹、已配置映射盘或外部同步目录仍可使用；云端传输进度由外部客户端负责。

正文仍默认DOCX、宋体五号10.5磅，段首是两个可复制的真实全角空格；固定Markdown资料、严格多书隔离和原稿保护继续适用。完整酒馆插件生命周期、完整Word排版、正式签名和自动更新仍未完成。

## 安装与验证

两台电脑先保存退出并保留整书和固定资料备份，再安装同一测试版；不要先卸载旧版或删除历史。模型连接由两台设备分别配置。安装包及对应源码不包含作者的NAS地址、账户、密钥或小说；测试版未签名，请核对同版`SHA256SUMS.txt`。

类型检查与生产构建通过；完整1023项核心、261项相关核心、11套不同相关桌面及34项安装保护测试通过。实际打包应用的ASAR归档与导入、隔离环境中的beta.1→beta.7运行目录升级模拟、安装器实际提取内容核对和隐私规则扫描通过。这些验证不代表真实NSIS覆盖安装、第二台设备或官方客户端跨网传输已通过。

安装器大小为118,059,483字节，SHA-256：`765f50985179cf4103f03129d0ecbaef5da6c99cfe2b3c2404856b8f0cc30c4e`；签名状态为NotSigned。
