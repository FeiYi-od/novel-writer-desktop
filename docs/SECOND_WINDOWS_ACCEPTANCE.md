# 两台 Windows 接力验收（临时小说）

更新：2026-10-26。使用同版本安装包和虚构测试小说。两台机器不需要处于同一局域网，也不要求都有 IPv6；远端访问和传输由 NAS 或网盘官方客户端、已配置挂载或手动完整文件交接提供。真实断网测试已移出当前验收。beta.5正则隔离/社区导入见[本版验收](BETA5_ACCEPTANCE.md)，既有历史ZIP导入见[beta.4步骤](BETA4_ACCEPTANCE.md)，Word/历史操作见[beta.3步骤](BETA3_ACCEPTANCE.md)，发布状态以同版Release为准。

## 安装与隐私

从项目 GitHub Release 下载本轮 Windows x64 测试安装包，在两台机器安装相同版本，并核对发布的 SHA-256。
这是未签名的测试构建。发布内容不含作者的 NAS 地址、账号、API 密钥、小说或本机开发日志。
每台机器单独配置自己的模型连接，密钥不通过小说目录复制。

升级前先在旧应用中保存并退出，保留原安装目录及小说的完整备份。安装程序先核对并保留旧安装目录旁的创作资料；失败会停止安装。新版固定资料位于 `%APPDATA%\novel-writer\创作资料/<projectId>/`，测试环境使用单独的应用数据目录。不要先手动卸载旧版或删除它旁边的“创作资料”。为所有用户安装的旧版需要另行处理，本测试安装程序会停止该类升级。详见[安装资料保护](INSTALLER_SAFETY.md)。

## 先验收正文接力

1. 使用 NAS 或网盘官方客户端、映射盘或挂载工具，让两台机器都能访问同一个**临时测试小说目录**。盘符、设备路径可以不同。
2. A 机打开该目录，新建 DOCX，输入“甲机第一轮。”，保存并退出。等待客户端完成同步/上传，再操作 B。
3. B 机在应用中打开相应目录，核对同一章节内容；追加“乙机第二轮。”，保存并退出，再等待同步完成。
4. A 机重新打开，核对两轮文字都存在。复制一段到普通文本框，确认段首是两个可复制的全角空格。
5. 记录两台机器版本、访问方式、是否收到冲突提示、能否用 Word/WPS 打开保存后的 DOCX；不需要提供公网地址、账号或密钥。

同步/挂载由服务商客户端提供；TCP 可达不代表文件同步完成。两台机器轮流操作，同步结束后再换机。

## 创作资料也要单独验收

1. A 创建虚构人物卡和世界观，正常确认或保存。打开“固定资料同步…”，启用并点击“立即同步”，确认成功后保存并退出。
2. 完整传输本书目录，包括 `小说资料/创作资料同步/版本/` 下的全部文件。只传 DOCX 不够；另一端固定资料不通过复制整个 AppData 获取。
3. B 打开本书，应用核对镜像并载入 B 自己的固定资料目录；如果 B 曾手动停用本书同步，先在“固定资料同步…”中重新启用。核对人物卡、世界观和 `projectId`。B 保存明确的资料修改，保存退出后回传整个小说目录；A 再打开核对。
4. 若出现资料冲突，保留双方，先选择远端版本，再逐文件选择。未确认前不自动覆盖；选择过期时重新预览。不要删除目录或改 ID 来绕过提示。
5. 应用已打开期间收到另一端更新时，先保存当前修改，再点“立即同步”，或重新打开本书。应用不轮询外部客户端的传输状态。

应用本机隔离配置验证不能代替具体官方客户端的跨网络验收。详见[固定资料同步](MATERIAL_SYNC.md)与[目录兼容](STORAGE_COMPATIBILITY.md)。

完整备份另行核对：在 A 使用“备份到文件夹”或“导出整本书 ZIP”，在新的空目录恢复，再打开核对正文、人物卡、世界观与 ID。恢复不会覆盖已有资料或小说；若已有相同 ID 的书，使用独立测试环境。完整备份迁移与镜像接力分别记录结果。

## 当前暂缓

- 无 IPv6 的环境使用服务商官方外网接入或手动完整文件交接，不从网页可访问推断 SMB 穿透已可用。
- 酒馆插件先做源码与离线夹具适配，尚未执行完整上游插件运行测试。
- 百度网盘、迅雷云盘等官方 API 直连另做账号授权、能力及冲突机制验证；本轮不需要用户提交账号或 Cookie。
