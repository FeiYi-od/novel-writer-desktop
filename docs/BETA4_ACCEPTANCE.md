# beta.4 安装与历史ZIP导入验收

更新：2026-10-25。通用验收步骤不代表已运行真实安装或设备联调；下载时核对同版Release及SHA-256清单。既有正文、历史浏览及Word副本功能可沿用[beta.3验收步骤](BETA3_ACCEPTANCE.md)。

## 升级前后

1. 两台电脑在旧版保存并退出，等待所用同步客户端完成传输，保留整本书和固定创作资料的完整备份。
2. 不要先卸载旧版或删除安装目录旁的“创作资料”。安装程序沿用升级前校验备份和迁移保护；冲突时保留双方及备份，不清空目录绕过提示。详见[安装资料保护](INSTALLER_SAFETY.md)。
3. 从同一次Release下载Windows x64测试包，核对同版 `SHA256SUMS.txt`；两端使用同版本。测试包未签名，最终状态以发布记录为准。
4. 升级后确认书架仍关联原目录，正文、小说ID、人物卡和世界观可读。模型连接在每台机器独立配置，不复制整个应用数据目录或提交账户、密钥作验收材料。

## 准备一份完整历史归档

使用单独的临时虚构小说，不用真实连载原稿。

1. 写入一条虚构世界观，保存并启用“固定资料同步…”，点击“立即同步”。再修改世界观并同步，保留至少一个较早版本。
2. 进入“历史版本与原稿保护”→“浏览历史与找回资料”，选择较早版本，点击“打包历史ZIP”。
3. 保留整个生成目录，其中应有原名 `历史资料.zip` 和同目录 `完成清单.json`。不要重命名ZIP；只传ZIP或没有完成清单的暂存不能导入。内侧 `manifest.json` 与外侧完成清单分别参与核验。

## 核对并导入为新副本

1. 在同一本小说的历史窗口点击“导入历史ZIP…”，再点“选择历史ZIP…”。先取消一次，确认不产生导入副本；随后选择准备好的 `历史资料.zip`。
2. 核对页面的ZIP名称、大小、SHA-256及文件列表，选择世界观文件查看当前与归档内容。Markdown、TXT和JSON显示纯文本，最长16,000字符；二进制只显示哈希说明，完整原字节仍会保存。
3. 先保存正文及各页资料，再点击“确认导入为新副本”。核对只生成一份新目录 `小说资料/资料历史导入/<UUID>/files/`，根目录有 `manifest.json`，其类型为 `material-history-import-copy`。可点击“复制导入副本目录”。
4. 核对副本中的旧世界观、DOCX或TXT内容；正文段首的两个真实全角空格应保留。当前世界观、正式人物卡、同步基线、历史版本和原始ZIP/完成清单均应保持原样。“仅当前存在”的文件不会加入归档副本，未确认草稿不会变成正史。
5. 成功后同一预览不能再次点击生成副本。确需再次导入时，重新选择完整归档，核对后发起新的操作。

预览15分钟有效；同一本书重选ZIP会使旧票据失效。超时或来源、当前资料发生变化时，按提示重新选择并核对，不修改小说ID绕过归属检查。

## 拒绝与保留检查

以下步骤仍只使用虚构测试目录，各项分别恢复到完整归档后再进行。

| 情况 | 预期结果 |
| --- | --- |
| 选择另一部同名小说的归档 | 按小说ID拒绝，不在当前小说生成副本 |
| 缺少外侧完成清单、ZIP改名或内容损坏 | 明确拒绝；保留现有资料和归档原件 |
| 有未保存正文或资料时确认导入 | 阻止导入，保留未保存输入 |
| 选择ZIP后，在外部修改ZIP、完成清单或当前资料 | 旧预览不能继续完成，要求重新选择 |
| 读取、原生选择器或导入仍在处理 | 关闭、重复操作和退出受到保护；完成后可以正常关闭 |
| 导入目标内容或目录身份在来源最终复核期间变化 | 拒绝写入成功清单，保留变化后的暂存和原件；此项由确定性自动回归验证 |
| 历史恢复副本或历史ZIP在最后一次来源复核期间变化 | 同样拒绝写入完成清单，保留源历史及当前资料；已有流程在本版一起修复 |

没有完成 `manifest.json` 的导入暂存不能当作完整副本。失败提示不要求删除旧历史、清空正式资料或覆盖原稿。

## 范围、接力与记录

ZIP最多80MiB，归档原文最多64MiB，单文件32MiB，内外清单各最多8MiB，ZIP总展开最多72MiB、最多10,002条目。仅接收本应用的非流式STORE/DEFLATE历史格式；加密、ZIP64、分卷、路径链接、等价重复或越界条目明确拒绝。更多限制见[资料历史](MATERIAL_HISTORY.md)。

接力写作按[两台Windows验收](SECOND_WINDOWS_ACCEPTANCE.md)完整传输小说目录；要移动历史归档时，同时传输原名ZIP及其完成清单。远端连接和实际上传/下载由已配置的外部客户端、挂载或完整手动文件交接提供。无需两端处于同一局域网，也不要求两端都有IPv6；应用不能确认服务商云端进度。

记录版本、访问方式、步骤结果、错误提示及副本文件名即可，不记录个人地址、账户或API密钥。导入副本向正式资料的一键换入、自动确认正史、历史批量清理、完整插件运行、网盘账户直连和官方自动同步实机仍分别待做。真实断网测试不纳入本轮验收。
