# 星序 starwriting beta.18 验收

本版为未签名的 Windows x64 预发布版。使用独立虚构小说验证，安装前保存退出并备份小说目录和本机创作资料。

1. 打开后核对顶部版本为 `0.1.1-beta.18`。“我的书架”的每张作品卡新增“移除”。
2. 点击“移除”，确认框明确只取消本机书架关联；选择取消应保留作品。确认后作品应从本机书架消失，重启不会自动回来。
3. 用资源管理器检查原文件夹与 DOCX/TXT 原稿仍在，人物卡和世界观等固定资料也保留。选择“打开小说文件夹”重新关联原目录，检查封面、分集与创作资料能够继续使用。
4. 打开两部虚构小说：移除非当前作品，不应清空当前正文；移除当前作品，应回到书架并清空当前编辑会话。
5. 正文或隐藏页面有未保存内容时先拒绝移除，输入保留；请回原页面保存/处理后重试。模型任务运行时先完成或取消，不会因移除而自动停止收费请求。

移除不是磁盘删除，也不会清除本机历史或恢复草稿，不向其他设备同步“删除”指令。只取消本机索引中的目标目录，其他书和暂不可访问的目录记录保留。

自动验证使用虚构文件、本机模拟模型与隔离应用数据；真实安装覆盖和作者真实作品未用于测试。如果外部程序正在修改本机书库索引，请结束操作后再移除；失败时先保留原文件和错误提示以便核对。

下载同版 x64 EXE 即可使用，无需安装开发环境。源代码 ZIP、许可、版本说明和校验清单位于同一公开发布页。NAS/网盘账户直连暂未开放。
