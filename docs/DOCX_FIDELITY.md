# DOCX 保真副本能力（2026-10-20 / 031）

外部 Word/WPS DOCX 在正文页使用“另存保真副本”打开真实段落编辑弹窗。所有写入均生成唯一新副本；原稿来源哈希在发布前再次校验。本文限定支持范围，不代表完整 Word 替代。

| 能力 | 当前入口 | 限定与保护 |
| --- | --- | --- |
| 正文改字 | 实际分页段落界面，50段一页、Ctrl+S | 未修改的多run XML保持原样；修改段落写入首个文本run，保留其样式，后续文本片段清空；不支持逐字新样式 |
| 尾部添删 | 段落界面 | 新段只复制段落/文字样式，不复制图片/书签/ID；删除含图片、节、书签、批注、脚注、域或修订的末段拒绝 |
| 表格行增删 | 安全IPC与桌面用例 | 目前没有专用可视化表格编辑面板；不宣称支持合并单元格/列宽拖动 |
| 页眉页脚文字 | 安全IPC与桌面用例 | 仅已有受支持部件，未修改部件不变；尚无专用可视化面板 |
| 图片替换 | 原生文件选择器授权的安全IPC | 仅已有PNG/JPEG目标，检查实际格式、大小与来源版本；不能由renderer随意读取本地路径；尚无专用图片替换面板 |
| 保存并退出 | 弹窗按钮及应用退出保存注册 | 失败留窗并保留输入；外部版本变化不能覆盖；未改动无需另存 |

限制：只扫描表格外正文段落；不支持文本框、域、修订痕迹文字改写，不能删除带保护结构的段落。图片环绕/裁切、复杂表格格式、域自动更新、WPS专有文件、页式排版均未实现。段落边界只允许末尾增删，避免中间错位。改变含多种行内格式的段落不能保证原来的逐字样式分布；原稿保留供Word/WPS继续处理。

输入DOCX最大20MiB、最多4096 ZIP条目、累计解压64MiB。解压前后核对目录、实际展开大小、重复路径与结构；正文最多10000段/8MiB，单段100000字符。无效路径、未知小说、缺失/过期来源哈希、ZIP64、加密压缩包、伪造尺寸等明确拒绝。

本轮验证：docx-fidelity/save-status及安全复制相关核心、完整582核心通过；fidelity、docx-structure、fidelity-safety、fidelity-editor、save-badge-ui桌面最终通过。新界面实际验证原稿/表格/图片/页眉保留、尾部空格、Ctrl+S、副本关闭确认、外部修改拒绝及退出留窗/成功退出。旧三个DOCX桌面夹具原缺合法命名空间，补正后通过；未掩盖首轮失败。
