# DOCX 保真副本能力（2026-10-29 / 本地开发版 057）

外部 Word/WPS DOCX 在正文页使用“另存保真副本”打开真实段落编辑弹窗。所有写入均生成唯一新副本；原稿来源哈希在发布前再次校验。本文限定支持范围，不代表完整 Word 替代。

beta.3包含037/038新增表格、页眉页脚及图片替换界面，beta.2尚无这些界面。057 在本地开发版新增正文中间插删，尚未打入已发布 beta.8。正文段落有未保存修改时，先另存保真副本，再打开新副本编辑结构或图片；不会隐式舍弃正文输入。

| 能力 | 当前入口 | 限定与保护 |
| --- | --- | --- |
| 正文改字 | 实际分页段落界面，50段一页、Ctrl+S | 未修改的多run XML保持原样；修改段落写入首个文本run，保留其样式，后续文本片段清空；不支持逐字新样式 |
| 正文段落前后插入、删除 | 段落界面，选中正文段后使用插入/删除按钮 | 以原段固定索引处理，表格等原位置及未改段XML不动；本批插删合计最多200段，至少保留1段。新段以宋体五号和两个真实 U+3000 开头，不复制原段的编号、样式、图片、书签或 ID。复杂段和非正文直接子段只读；跨段域、跨段书签/批注/权限等范围使正文保守只读。插入可放在普通复杂段前后，但不会编辑或删除它 |
| 表格单元格文字、行增删 | Word保真副本内“表格与页眉页脚…” | 简单平面矩形表格按单元格/段落编辑，行操作与文字改动在内存中统一处理，最终只另存一份；合并/嵌套/域/图片等复杂结构只读说明，不支持列宽拖动 |
| 页眉页脚文字 | 同一结构面板 | 仅已有受支持部件的各段文字；复杂部件只读，未修改部件原字节保留；不新增页眉关系或页面布局 |
| 图片替换 | Word保真副本内“替换已有图片…” | 选择已有PNG/JPEG部件，通过原生文件选择器选有效PNG/JPEG，按目标格式转换后只另存一份；保留布局和其他部件，共用同一media的引用一同更新；其他格式只读 |
| 保存并退出 | 弹窗按钮及应用退出保存注册 | 失败留窗并保留输入；外部版本变化不能覆盖；未改动无需另存 |

限制：只扫描表格外正文段落；不支持文本框、域、修订痕迹文字改写，不能删除带保护结构的段落。图片环绕/裁切、复杂表格格式、域自动更新、WPS专有文件、页式排版均未实现。新段不会继承原段编号或格式；改变含多种行内格式的段落不能保证原来的逐字样式分布；原稿保留供 Word/WPS 继续处理。空白且没有任何正文段落的外部文档目前没有插入锚点，请先用 Word/WPS 添加一段。

输入DOCX最大20MiB、最多4096 ZIP条目、累计解压64MiB。解压前后核对目录、实际展开大小、重复路径与结构；正文最多10000段/8MiB，单段100000字符。无效路径、未知小说、缺失/过期来源哈希、ZIP64、加密压缩包、伪造尺寸等明确拒绝。

结构批量最多100个动作、合计8MiB文字，索引依次对应之前动作后的文档；任何一项失败都不发布半成品副本。界面保存退出注册包含结构草稿；来源变化时拒绝并保留窗口。新核心用例见 `tests/docx-structure-ui.test.ts`，真实界面用例见 `tests/docx-structure-ui-desktop.ts`，本批最终执行结果以037交接记录为准。

替换图片最大20MiB（转码后目标部件也受20MiB限制）、单边16384像素、总3200万像素；解码前检查PNG/JPEG容器与尺寸，再由nativeImage验证像素解码及尺寸。不接收APNG、多图MPO等复杂格式。选择器取消不会生成副本，选择期间来源变化会拒绝发布；忙期禁止关闭/退出，正文草稿保留。此功能不插入新图片、不调整图片的页面大小或裁切，不读取外部链接图片。PNG与真实JPEG→PNG转码均已做真实界面验证，原稿和无关ZIP部件保持原字节；未运行真实Word/WPS程序验收。
