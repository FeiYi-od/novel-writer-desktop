# 星序 starwriting beta.17 验收与升级

这是未签名的 Windows x64 预发布版。请使用虚构小说完成初次验收，保留原稿及本机创作资料备份。

1. 从本版发布页下载 `starwriting-0.1.1-beta.17-x64.exe`，关闭正在运行的星序/小说编写器后安装。无需安装开发环境。
2. 安装界面及新快捷方式应显示“星序 starwriting”，打开后页眉显示 `0.1.1-beta.17` 与星芒轨道图标。内部 `小说编写器.exe` 和 `%APPDATA%\novel-writer` 继续保留，属于兼容标识。
3. 若提示新旧快捷方式冲突，安装已在卸载前停止。先核对链接目标，将需保留的快捷方式改成不同名称，再重试；不要删除小说或创作资料。未被安装器管理的自定义链接不会被全盘搜索修改。
4. 新建两个虚构小说，分别保存 DOCX 章节，重开核对内容隔离、宋体五号和可复制的两个全角空格。测试外部改稿时应拒绝旧基准覆盖。
5. 从“更多功能 → 检查更新”核对版本，Tab/Shift+Tab 应在窗口内移动，Escape 关闭。公开仓库可直接查询；私有仓库需本次只读令牌，或在已授权登录的浏览器打开发布页。

自动验证使用临时虚构数据及本地模拟：类型检查、生产构建、核心测试、更新窗口/正文桌面回归、实际打包程序及隔离升级模拟。NSIS 保护钩子使用独立测试安装器验证；这不等同于在作者真实安装和资料目录执行覆盖安装。具体统计记录在开发交接中。

真实 Windows 安装覆盖、真实 Word/WPS 全格式和所有外部账号/两机联调仍待验收，不能将测试通过视为全部功能无缺陷。NAS/网盘账户直连暂未开放。
