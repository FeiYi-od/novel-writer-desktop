# NAS 与网盘目录兼容

更新：2026-10-20。本页记录已实现范围与接入条件，不代表已经通过各品牌真机验收。

当前应用通过普通 Windows 文件夹读取、保存小说，不绑定某个 NAS 品牌。NAS 共享目录、映射盘、官方同步客户端产生的本机文件夹，以及已配置的可读写挂载目录，均使用同一文件访问流程。应用保留保存前版本检查、冲突副本和本机草稿保护；不会凭本机保存成功就声称云端同步完成。

| 设备或服务 | 当前可用方式 | 仍需配置或验证 |
| --- | --- | --- |
| 通用 NAS，包括飞牛、群晖、威联通等 | 用户先在 Windows 连接共享目录/映射盘，或先配置官方同步客户端，再从书架打开其小说文件夹 | 外网连接、账户登录、权限、真实双机接力由对应环境验收 |
| Synology Drive | 在 Drive Client 建立双向同步，打开本机同步文件夹 | 具体设备/账户授权与双机实测；文件应实际下载到本机 |
| QNAP Qsync | 在 Qsync Client 配对文件夹，打开本机同步目录 | 具体设备/账户和双机实测 |
| 百度网盘 | 客户端与账户提供同步空间时，先配置同步并下载到本机，再打开该文件夹；无双向同步时使用整书 ZIP 手动备份/转移 | 同步空间实际权限；内置 OAuth 登录、API 直传和自动同步队列尚未实现 |
| 迅雷云盘 | 已有工具提供可读写 Windows 文件夹时使用目录流程；否则导出整书 ZIP 后手动上传/下载 | 不假定普通客户端提供任意文件夹双向同步；内置云盘登录/直传尚未实现 |
| OneDrive | 打开已配置同步目录，建议设为“始终保留在此设备上” | 账户、按需文件本地可用状态与双机实测 |
| 其他网盘 | 支持本机双向同步/可写挂载时走目录流程；仅网页上传时使用整书 ZIP | 各客户端能力和写入语义分别验收，不等同于通用直连 API |

## 两台电脑轮流写作

1. 先用不含真实内容的测试小说验证。两端目录可以使用不同盘符，但必须对应同一远端目录，并保留 `小说资料/project.json` 中同一个 `projectId`。不要复制同一本书并在同一应用中作为两本独立作品关联。
2. A 保存并退出本书，等官方客户端显示同步完成，再让 B 下载最新文件并打开。B 完成后按相同步骤交回 A。
3. 只有“上传备份”或“自动备份”不保证 B 的修改会自动回到 A；必须确认所用工具支持并启用了双向同步。
4. 本文不恢复用户已暂停的真实断网验收，也不把本机临时模拟当作跨网络真机通过。

### 正文之外的资料

正文与书目录内元数据随小说文件夹传输。人物卡、世界观、文风等权威 Markdown 位于应用固定的 `创作资料/<projectId>/`，**仅同步小说正文文件夹不会自动同步该目录**。完整接力需要另外配置资料目录同步，或使用包含本书固定资料的整书备份/ZIP 进行迁移。运行中的 SQLite 索引、临时记录、加密密钥及本机应用状态不作为共享小说文件同步。

应用当前提供“备份到文件夹”“从备份恢复”“导出整本书 ZIP”。这些操作可用于 NAS 或网盘同步目录，但不会代替官方同步工具，也不会上传账号或凭据。

## TCP 检查和发布隐私

面板默认目标为空，选择设备仅显示说明，不自动连接。域名、IPv4、`[IPv6]:端口` 和不带端口的 IPv6 均可输入；省略端口时明确使用 443。最多 8 项，错误注明行号且整批拒绝，不悄悄忽略。TCP 可达只证明对应端口能建立连接，不证明共享目录可写、已登录或云端同步完成。

生产源码的面板默认值不含用户地址、域名、共享路径、账户或 API 密钥。发布检查仍需对最终构建与安装包单独检查，不能由本页或测试替代。

## 官方来源与后续直连接口

以下网页于 2026-10-20 查阅，只摘取与目录模式和接入条件直接相关的内容，未复制 SDK 代码。

- [飞牛同步 FAQ](https://help.fnnas.com/articles/v1/sync/fnsync-faq)：隐藏文件不参与同步、冲突副本与占用文件的处理，因此不能只验证正文到达。
- [Synology Drive Client 官方帮助](https://kb.synology.cn/zh-cn/DSM/help/SynologyDriveClient/synologydriveclient?version=7)：可配置本机/服务端文件夹与双向同步，支持 IPv6；账户权限和按需规则由官方工具处理。
- [QNAP Qsync 官方介绍](https://www.qnap.com.cn/zh-cn/software/qsync)：Qsync Client 选择本机/服务端文件夹，使文件保持同步。
- [百度网盘官网](https://pan.baidu.com/)与其[官方服务域页面](https://d7.pcs.baidu.com/)介绍同步空间；本轮官网完整页面抓取受限，不据此承诺具体账户免费可用。客户端实际显示的功能和权限才是配置依据。
- [百度网盘开放平台](https://pan.baidu.com/union)及 [baidu-netdisk SDK](https://github.com/baidu-netdisk/baidu-drive-sdk-go)：平台提供文件操作及 OAuth 授权方向，未来直连需要应用注册、授权与刷新凭据流程。平台文档入口本轮抓取失败；SDK README 可读，不把该调研记为 API 接通或真实授权测试。
- [迅雷官方开放平台文档](https://open.xunlei.com/doc)当前公开入口是下载 SDK 和宿主微应用；[下载接入说明](https://open.xunlei.com/doc/download/guide/quick-start)要求创建应用、API Key 与认证。这些下载能力不等同于第三方小说编辑器的云盘双向读写接口。本轮未确认可直接使用的通用云盘文件同步 API，因此不实现猜测协议或抓取用户 Cookie。
- [迅雷私有云官网](https://xlnas.xunlei.com/)介绍特定 NAS 产品的迅雷云盘同步，但该设备能力不能推断为所有 Windows 迅雷客户端均具备任意目录双向同步。
- [Microsoft OneDrive 同步帮助](https://support.microsoft.com/zh-cn/onedrive/sync-your-computer-s-files-and-folders-with-onedrive)：官方客户端在电脑与云端同步目录，并区分仅联机/本地可用文件。

下一阶段按提供商独立实现和验收 OAuth/令牌安全存储、目录选择、冲突双副本、断点续传与同步状态；有官方授权应用后再进行真实账户联调。账号接入不会出现在通用安装包的预置数据里。
