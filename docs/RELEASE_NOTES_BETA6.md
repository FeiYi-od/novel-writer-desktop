# 小说编写器 0.1.1 Beta 6

Windows x64测试版。本版修复资料历史满额时的写入边界，并增加独立的历史目录容量显示；beta.5及旧版附件保留。

## 本版改动

- 历史面板分别显示本机替换前归档、书内传输目录的条目与剩余名额，800开始预警、上限1,000；超限显示“至少1,001”。历史列表读取失败时仍可查看容量，读取不重放中断换入或触及正文。
- 修复传输目录恰满1,000时可能留下第1,001个未完成目录、本机历史满额后仍继续归档的问题。按实际需要在发布/暂存前预检两侧，再在实际写入前复核；不删除历史或父节点。
- 满额时，不新增该侧历史的操作仍可进行，例如无改动核对、纯推送、无需新传输版本的拉取；已核验历史仍可另存副本或ZIP。ZIP留档不会释放名额，完整DAG批量归档与清理仍待做。

沿用beta.5的社区正则JSON导入、原字节/扩展保留和可取消隔离预览，见[beta.5操作](BETA5_ACCEPTANCE.md)。正文默认DOCX、宋体五号10.5磅及两个可复制的真实U+3000；固定Markdown资料、多书隔离、原稿保护继续适用。

## 安装与验证

两台电脑先保存退出、保留整书与创作资料备份，再安装同一版本。不要先卸载旧版、删除历史或复制包含密钥的整个AppData。模型连接由两端独立配置；安装包和对应源码不包含作者NAS信息、账号、密钥或小说。本包未签名，下载后核对同版`SHA256SUMS.txt`。

功能代码通过完整884核心、118相关核心及6套不同桌面，0失败/跳过；包括容量边界、满额写前保护、外部交错、错书/迟到结果、DOCX和原资料字节保护。升beta.6后类型检查、生产构建及34项升级/便携/独立NSIS钩子保护测试通过。

本版实际ASAR的容量界面已执行800→1,000→1,001、列表失败时独立容量、满额副本/ZIP、错书/延迟响应及保存退出重开验证。复制允许runtime的beta.1→beta.6隔离升级模拟通过，旧资料/备份、加密假模型配置、DOCX与真实U+3000保持。安装器提取的asar及保护脚本与runtime一致，包内7个out部件与构建逐字节一致；src/out/实际asar/resources隐私规则无发现。只用虚构作品和隔离配置，不运行正式NSIS覆盖用户安装，不将模拟当成第二台设备或官方跨网验收。

安装包118,051,584字节，SHA-256：`0953ae0837c67ec6ca622aa7957ded73d4a25d0d72ea2c5d560be7b46dd18752`，NotSigned。对应过滤源码及全部附件摘要随同版`SHA256SUMS.txt`交付。
