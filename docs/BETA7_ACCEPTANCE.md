# beta.7 安装与完整历史验收

更新：2026-10-27。以下是用户设备上的人工步骤，尚不代表实际安装或跨网传输已经验收。

两台Windows保存退出、保留完整小说及固定资料备份，下载同一版本并核对`SHA256SUMS.txt`。不要先卸载旧版、删除历史或复制包含密钥的整个AppData；模型连接分别配置。[安装资料保护](INSTALLER_SAFETY.md)和[两机接力](SECOND_WINDOWS_ACCEPTANCE.md)继续适用。

## 归档与导入

1. 使用独立虚构测试小说，进入“固定资料同步…”→“历史版本与原稿保护”→“浏览历史与找回资料”。需要至少一份有效历史。
2. 点击“完整历史归档…”，核对书内版本、本机归档、当前分支及数据量，生成完整历史ZIP。保留生成目录里的 `完整资料历史.zip` 和 `完成清单.json`。
3. 返回历史面板，点击“导入完整历史…”，选择原名ZIP。核对归属和摘要后选择“确认导入为新副本”，复制输出目录。
4. 查看新目录中的 `transport/<版本ID>/manifest.json`、`transport/<版本ID>/files/`、`local/<归档ID>/` 和根 `manifest.json`，核对各版本与原文件。当前设定、既有历史和同步基线不变，草稿不会自动成为正史。
5. 另一部同名小说选择此包应被拒绝；来源或当前资料变化后需重新选择。单版本 `历史资料.zip` 使用“导入历史ZIP…”入口，不能与完整历史包混用。

ZIP不会删除旧历史或释放1000条目名额。完整包的系统权限和目录时间不作为文件内容保存；嵌套空目录、未完成上传、缺父、损坏或超限会停止，保留原件。预算和操作细节见[资料历史](MATERIAL_HISTORY.md)。
