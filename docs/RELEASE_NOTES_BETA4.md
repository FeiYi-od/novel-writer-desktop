# 小说编写器 0.1.1 Beta 4

Windows x64 测试版，安装包尚未签名。两台电脑请使用同一版本；升级前保存并退出，保留完整备份，不要先卸载旧版。beta.3 已发布的附件保持原样。

## 本版改动

- **历史ZIP导入**：在“历史版本与资料找回”中选择“导入历史ZIP…”，读取本应用生成的原名 `历史资料.zip` 及同目录 `完成清单.json`。核对内外清单、小说ID、ZIP与逐文件SHA-256后，先展示当前资料和归档内容的对照，再由作者确认导入。
- **独立副本与多书隔离**：完整归档另存到本书 `小说资料/资料历史导入/<UUID>/files/`，最后写入该副本的完成清单。另一部同名小说的归档会拒绝；正式人物卡、世界观、同步基线、历史版本关系和原始归档保持不变。未确认草稿保留原标记，不自动成为正史。
- **预览及操作保护**：预览15分钟有效，同一本书重新选择归档后旧票据失效，成功票据不能重复生成副本。导入前要求先保存各页修改；读取、选择及写入期间禁止重复操作，并接入关闭和保存退出保护。
- **完成清单保护修复**：导入、历史恢复副本及历史ZIP留档，都在最终来源复核后再次核对目标内容。导入还核对目标目录身份；目标被外部改写或替换时，保留暂存并拒绝写入成功清单，避免将变化后的副本或ZIP误报为完成。已有beta.3的恢复副本/留档检查次序也在本版修复，旧版本附件保留。

只接收本应用的单版本历史归档及完成清单，缺失、改名、错书、未知格式或损坏时明确拒绝。ZIP最多80MiB、归档原文最多64MiB、单文件32MiB；内外清单各最多8MiB，ZIP总展开最多72MiB。解压前校验目录并限制实际输出，拒绝加密、ZIP64、分卷、链接、重复或越界路径。文本以纯文本预览，最长16,000字符；其他文件保存原字节。

beta.3的资料历史浏览、历史ZIP留档，以及正文、简单表格、已有页眉页脚和PNG/JPEG图片的保真副本编辑继续保留。正文仍默认DOCX、宋体五号10.5磅，段首为两个可复制的真实全角空格。更多既有能力和限制见[beta.3验收指南](BETA3_ACCEPTANCE.md)及[Word副本能力](DOCX_FIDELITY.md)。

## 安装与接力写作

两台电脑使用同一版本。升级前先在旧版保存并退出，保留整书及固定创作资料的完整备份；不要先卸载旧版或删除安装目录旁的“创作资料”。沿用稳定应用数据目录及升级前校验备份保护，发现冲突或旧应用仍运行时停止。详见[安装资料保护](INSTALLER_SAFETY.md)。

归档跨设备传递时，应完整带上ZIP所在目录及外侧完成清单。模型连接和密钥由每台机器独立管理，不复制整个应用数据目录。发布内容不包含作者的NAS连接信息、账户、API密钥、小说或私人开发日志；外部客户端仍负责实际传输。

修复后完整784项核心测试、87项相关核心、5套相关桌面回归、类型检查及构建通过，0失败或跳过。确定性回归先复现最终来源检查期间目标变化仍写成功清单，再验证导入、历史副本和ZIP留档三流程修复。升为beta.4后重新通过类型检查、构建和34项升级/便携打包/独立NSIS钩子核心测试。

实际安装器118,044,254字节，SHA-256为 `331be3302c6d810cb62e8d3c83b49cc850b784854a0f73513c1dc26132437a55`。提取的应用归档及升级保护脚本SHA与构建文件一致，源码、构建、实际应用归档与保护资源隐私规则扫描无发现。下载时同时核对同版Release及 `SHA256SUMS.txt`。

隔离packaged beta.1→beta.4升级模拟通过，核对旧资料及备份、JSON迁移、小说ID/DOCX原字节/真实全角空格、加密假模型配置、凭据不随传输、历史预览、保存退出及重开。打包应用中的导入面板只读入口也已验证；实际导入流程在开发构建桌面回归验证，不把入口检查冒充打包应用的完整导入验收。

验证只使用临时虚构作品和隔离配置。复制运行文件的升级模拟不等于真实NSIS覆盖安装；本机测试不等于第二台Windows或官方客户端跨网同步实测。下载时核对同版Release和 `SHA256SUMS.txt`。
