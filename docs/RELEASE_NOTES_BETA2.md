# 小说编写器 0.1.1 Beta 2

Windows x64 测试版，安装包尚未签名。两端请安装同一版本。升级前先在旧版保存并退出，不要先卸载旧版或手工清空它旁边的“创作资料”。

## 本版改动

- 新增固定资料随书同步：人物卡、世界观、文风、筹备和已确认摘要在打开及保存退出时核对；提供立即同步、逐文件冲突选择、并行版本选择及保留旧资料。
- 固定资料移到本机应用数据目录，Windows默认 `%APPDATA%\novel-writer\创作资料`，避免安装器更新应用文件时清理资料。旧版资料先生成完整哈希备份，再向空目标安全迁移；已有不同资料、文件变化或旧应用仍在运行时停止，不强制覆盖或结束写作进程。
- 修复时间线、人物关系、人物状态、提示词库、蓝图和文风版本的同名小说碰撞；改为本书目录内保存，严格校验小说ID及完整文件版本，旧文件保留并迁移，备份导出也包含未打开面板的旧资料。
- 修复酒馆正则导入预览的斜线flags、默认匹配、局部trim和捕获替换；不把数据交换兼容声称为完整插件运行。
- 便携打包拒绝覆盖既有运行目录或ZIP，保留旧版本与资料。

## 同步与隐私

固定资料的权威文件仍在每台机器的应用数据目录；启用同步后，完整小说文件夹内包含传输快照。请把“小说资料/创作资料同步”连同正文一起传输，再轮流写作。

NAS/网盘客户端负责传输。应用不提供百度/迅雷等账户直连，也无法确认官方客户端云端进度；密钥、模型配置、本机任务、用量与索引不随小说复制。发布包不含作者的NAS地址、账号、密钥、小说或个人开发记录。

## 验证与范围

类型检查、完整654项核心测试（无失败或跳过）、生产构建通过；保存退出、整书导出、固定资料同步3套相关桌面回归通过。相同安装前保护钩子的独立NSIS测试通过；隔离的已打包beta.1→beta.2升级模拟通过，验证正文和资料原字节、迁移备份、本机加密模型配置、传输凭据隔离以及保存退出后重开。

安装包内实际提取的应用归档和保护脚本与构建文件哈希一致，发布源码和应用文件的隐私规则扫描无发现。测试仅使用虚构作品、隔离配置和本机模拟服务，没有真实收费请求；没有在用户现有安装上执行覆盖安装，也没有把同机隔离测试记成第二台真机验收。

真实断网测试按用户要求不纳入当前验收。官方同步客户端双向任务、各网盘直连接口、完整酒馆插件及完整Word可视化排版仍未完成。旧版本发生资料冲突时，保留两侧和升级备份后再核对。

安装与接力步骤见同版 `BETA2_ACCEPTANCE.md` 和 `SECOND_WINDOWS_ACCEPTANCE.md`；源码及AGPL许可随本次发布提供，文件哈希见 `SHA256SUMS.txt`。
