# beta.3 安装与功能验收

更新：2026-10-25。以下为通用验收步骤，不把尚未执行的安装或设备步骤记为通过。须从同版Release下载安装包，并用其哈希清单确认文件完整。

## 安装前后

1. 两台电脑先在旧版保存并退出，等待自己使用的NAS/网盘客户端完成传输；保留整本书和固定创作资料的备份。
2. 不要先卸载旧版或删除安装目录旁的“创作资料”。新版沿用升级前校验备份与迁移保护；失败时保留文件和备份，先核对提示，不要清空目录来绕过冲突。详见[安装资料保护](INSTALLER_SAFETY.md)。
3. 从同一次Release下载Windows x64安装包，核对 `SHA256SUMS.txt`；两端使用同版本。安装包尚未签名，发布内容不包含作者的NAS连接信息或密钥。
4. 升级后核对书架仍关联原目录，小说ID、正文、人物卡和世界观可读。本机正式资料默认位于 `%APPDATA%\novel-writer\创作资料\<projectId>\`；旧资料的校验备份位于该应用数据目录的 `material-upgrade-backups`。安装根可能随升级替换，核对保留内容应以稳定资料目录和完整备份为准。
5. 模型连接仍由本机独立管理。不要把AppData、密钥或账户配置复制给另一台机器，也不需要提交密码或API密钥作为验收记录。

## 正文与历史资料

使用单独的临时虚构小说，不拿连载原稿作验收。

1. 新建DOCX，输入两段虚构文字并保存、退出、重开。核对宋体五号10.5磅；复制到普通文本框后，段首应有两个真实全角空格。
2. 保存一份虚构世界观，启用“固定资料同步…”并立即同步；再修改该世界观并同步，形成至少两个书内版本。进入“历史版本与原稿保护”→“浏览历史与找回资料”。
3. 选择旧版本，逐文件对照新旧内容。点击“恢复为新副本”，核对 `小说资料/资料历史恢复/<UUID>/files/` 和完成清单；当前世界观及正文应保持最新内容，旧副本不应自动成为正史。
4. 对同一已核验旧版本点击“打包历史ZIP”，核对文件路径、界面SHA-256与旁边的 `完成清单.json`。ZIP应含 `files/` 和内部 `manifest.json`；原版本和同步基线继续保留。传输归档时带上整个归档目录，不能只保留没有完成清单的暂存。
5. 有未保存正文/资料时尝试生成副本或ZIP，应明确阻止并保留输入。若预览后资料在外部变化，应要求重新预览；不要通过删除历史或修改小说ID消除提示。

ZIP仅压缩单个完整历史版本，原文最多64MiB、ZIP最多80MiB；更大快照可使用恢复为新副本（单快照最多256MiB）。新副本供核对和手动采纳，不能直接当作已恢复的正式资料。历史数量上限及其他限制见[资料历史](MATERIAL_HISTORY.md)。

## Word表格、页眉页脚与图片

准备一份独立虚构Word/WPS DOCX，包含普通正文、简单2×2表格、已有页眉页脚和内嵌PNG/JPEG。下列人工步骤不是已经运行真实Word/WPS的证明。

1. 在正文页打开该DOCX，进入“另存保真副本”。先修改正文，确认结构/换图入口要求先另存，不丢弃正文输入。
2. 在没有未保存正文的版本中进入“表格与页眉页脚…”，修改一个单元格、增加或删除一行、改写已有页眉页脚，点击“另存结构副本”。核对只生成一份新DOCX，原稿不变；打开新副本核对各项变化。合并/嵌套/域等不支持结构应说明并保持只读。单批最多100项动作、8MiB文字，单表最多1000行、10000格；界面达到上限时不能继续追加行。
3. 在另一份未改原稿中进入“替换已有图片…”，选择已有PNG/JPEG部件，点击“选择图片并另存副本”，再选择一张虚构PNG/JPEG图片。有效选择会立即另存，无需再次点击保存。核对只生成一份换图副本，原稿和其他部件保留；同一media部件若有多处引用，这些位置一同更新。取消选择不应生成副本。
4. 选择无效图片时，应提示拒绝并保留窗口。PNG/JPEG容器预检后仍须实际解码；最大20MiB、单边16384像素、总3200万像素，不接收APNG/MPO等复杂格式。其他目标图片格式只读，外部链接图片不读取。
5. 结构页有修改时，点击“保存副本并退出应用”，重开后核对新副本及原稿均在。若来源已由外部程序修改，应拒绝过期保存并保留输入；图片选择或另存过程中，关闭/保存退出应受保护。

这些入口另存副本，不提供完整Word页面排版、列宽拖动、图片裁切或新插图片。更多限制见[DOCX_FIDELITY](DOCX_FIDELITY.md)。

## 两台电脑与验收记录

按[两台Windows接力](SECOND_WINDOWS_ACCEPTANCE.md)完整传输临时小说目录，两端轮流操作。无需同一局域网或两端都有IPv6；远端访问由已经配置的官方客户端、挂载或手动完整文件交接提供。应用不能确认官方客户端云端传输进度。

记录版本、访问方式、上述步骤结果、错误提示及新副本文件名即可；不记录公网地址、账户或密钥。完整酒馆插件、网盘账户直连、官方自动同步实机和真实NSIS覆盖升级仍须分别验收。真实断网测试已按用户要求移出本轮范围。
