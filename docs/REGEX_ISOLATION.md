# 宏与正则预览隔离

更新：2026-10-26 / beta.5包含042隔离预览及043社区导入。beta.4及更早版本不含这些能力；安装与本版实际包验证见[beta.5验收](BETA5_ACCEPTANCE.md)。下方042验证保留为开发阶段记录。

在正文页打开“宏与正则…”，导入正则JSON数据，填写角色名和测试文本，再点击“预览”。042支持数组或`scripts`包装，043另补单条对象和[原始JSON保留](REGEX_IMPORT_043.md)。先展开支持的宏，再按脚本顺序替换；查看两栏纯文本，正文和人物/世界观均不会因此改写。不执行社区JavaScript或插件生命周期，也不调用模型。

正则计算在独立Worker中进行，默认最多3秒、全应用同时2个线程，同一小说只允许一个预览。计算时可点“取消预览”；只有线程终止后才释放容量。超时、取消、执行错误或来源变化时清除旧预览，不显示部分结果。磁盘读取和排队不算正则计算时长；排队时取消会阻止后续启动Worker。处理期间关闭和保存退出受保护，外层资料同步排队不会挡住取消入口。

每次请求固定小说ID、请求ID、输入、宏上下文及脚本快照，完成前再次核对小说目录和脚本版本。另一书或旧请求的取消不会终止当前书的新请求，迟到结果不能跟随界面当前小说。

## 上限与原脚本保护

| 内容 | 上限 |
| --- | --- |
| 预览输入 | 20,000字符 |
| 宏展开、最终结果 | 各200,000字符；替换过程逐步检查，不仅在结束后截断 |
| 脚本 | 256条 |
| 查找模式 / 替换模板 | 8,192 / 32,768字符 |
| trim条目 | 每脚本128条，每项8,192字符 |
| JSON文件与Worker请求总量 | 各1MiB |
| 角色名和作者名 | 各512字符 |

超限会明确拒绝，原文件保留。旧数组、无`projectId`的旧`scripts`包装继续可读；新保存包装带`schemaVersion:1`和`projectId`，错书或未知版本拒绝。导入替换现有脚本时，先在本书`小说资料/正则脚本历史/`保留原始字节，再检查当前版本和暂存后发布；链接、外部变化或暂存变化会停止，原件和暂存保留。预览不重写脚本文件。

原034的flags、捕获替换和trim语义沿用，见[兼容矩阵](REGEX_COMPATIBILITY_034.md)。未知宏保持可见，坏表达式仅跳过该条；这与超时/取消终止整次预览不同。仍不支持完整placement、promptOnly、depth、scoped优先级或任意插件执行。

## 验证范围

核心用例使用真正编译的可信Worker验证回溯超时、取消、容量释放、边界和替换语义；服务用例验证排队取消、双书隔离、来源变化、导入备份及版本保护。桌面用例验证界面心跳、取消/超时、退出保护和原稿原字节。

另用全新临时打包runtime的真实`app.asar`运行预览、超时、取消、同步排队及恢复预览，证明生产Worker路径可用。此测试使用虚构隔离配置，不运行NSIS、不替换现有安装，不等于真实升级或云端接力验收。每批最终执行结果在DEVLOG/HANDOFF记录。
