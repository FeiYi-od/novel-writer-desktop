# beta.14 本地测试和升级注意事项

本版是未经代码签名的 Windows x64 预发布测试版。升级前备份小说目录和本机固定创作资料，关闭本程序及可能同时写入同一小说的 Word、WPS 或同步程序。不要使用真实小说作为首次测试数据。

1. 在测试目录新建一本虚构小说，验证默认 DOCX、宋体五号和可复制的两个全角段首空格。
2. 测试保存、关闭并重开；分别验证 TXT 连续空行、同一本小说的正文与固定资料，以及外部修改冲突时是否停止并保留内容。
3. 在第二台设备使用同一同步目录时轮流写作：上一台保存并确认同步完成后，再到下一台打开。不要同时写同一章节；历史恢复会替换整套当前固定资料，操作前先阅读确认提示。
4. 图片或文字角色卡导入的未确认草稿重启恢复后，如提示临时数据失效，请重新选择原文件并核对；重新选择前不会确认导入。
5. 模型 API、网络服务和额度由使用者自行配置与控制。本版未验证所有供应商的真实账户；朱雀与模型 API 调用可能计费。

本版不是完整 Word 编辑器，也不是完整酒馆插件运行环境。NAS 和网盘账户直连暂未开放；用户自行配置的本地目录、挂载盘或同步文件夹由相应客户端负责文件传输。

如有异常，保留原稿和恢复目录，先复制备份，再记录重现步骤。开发测试不能证明所有外部程序、文件系统与网络环境下均无竞态。
