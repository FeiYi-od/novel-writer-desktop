# 星序 starwriting 0.1.1-beta.18

Windows x64 预发布更新，新增书架作品移除。

- 在“我的书架”每部作品卡片上增加“移除”按钮，确认后取消本机书架关联。
- 原小说文件夹、正文、封面、人物卡、世界观、恢复草稿和历史资料全部保留。通过“打开小说文件夹”选择原目录即可重新加入，沿用原 projectId。
- 有未保存的正文或资料、模型任务、保存退出或文件操作时，先提示完成后再移除。移除当前作品会清空当前编辑会话；移除其他作品保留当前书的编辑界面。
- 索引损坏、外部变化或写入失败时拒绝移除，保留原索引和书架关联；不删除原稿。

这是整合更新，包含 beta.17 的品牌、图标、更新窗口和本地创作功能。默认 DOCX、宋体五号、真实双全角空格不变。仓库和安装包已公开，下载不需要 GitHub 授权令牌。

下载 `starwriting-0.1.1-beta.18-x64.exe` 安装；源码 ZIP、验收说明与 SHA256 清单同版提供。安装包未签名，真实覆盖安装、Word/WPS 全格式和全部外部服务联调仍待验收，NAS/网盘账户直连暂未开放。
