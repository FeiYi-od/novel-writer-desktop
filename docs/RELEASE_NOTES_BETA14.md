# 小说编写器 0.1.1-beta.14

这是 Windows x64 预发布测试版，适合在备份后测试；不是稳定正式版。安装包未进行代码签名，Windows 可能显示安全提示。当前安装器不包含作者的 NAS 地址、账号、API 密钥或小说；使用者需要自行配置模型和文件目录。

## 相对 beta.8 的主要更新

- 修复正文保存暂存期间外部修改可能被覆盖的问题，增加保存前核对和恢复目录保护。多个程序或设备仍不应同时写同一章节。
- 完善固定资料历史浏览、整套还原和限定条件下的历史容量管理；还原前保留当前资料，并要求作者确认。角色卡、世界观等不会因草稿恢复自动成为正式设定。
- 增加外部 Word 文档受限的正文、表格、图片及段落排版副本编辑；原稿保留。复杂 Word 文档的全部格式尚不支持。
- 修复 TXT 空行往返、较长页面草稿被截断、模型账户共用目录缓存等问题。角色卡导入草稿恢复时，若原卡或头像的临时数据失效，需要重新选择文件，已编辑字段会保留。
- 改善书架搜索、长标题、键盘焦点与窄窗口显示。对酒馆角色卡及世界书的部分数据格式和宏提供兼容；这不代表支持运行全部酒馆插件。

## 使用和升级

安装前请备份小说目录及本机创作资料。安装后模型密钥由使用者自行配置；在不同电脑之间轮流写作时，先确认前一台电脑保存并完成文件同步，再在另一台打开。正式跨设备服务商联调尚未完成，NAS 和主流网盘的账户直连暂未开放。

本版未经过真实 Word/WPS 全格式验收、真实 NSIS 覆盖安装验收或全部模型供应商联调。模型 API 可能计费，请由使用者决定何时发起请求。安装器和源码校验值以本次发布附件中的 SHA256 清单为准。

源码及许可证随发布提供。完整功能边界与升级注意事项见同版验收说明。
