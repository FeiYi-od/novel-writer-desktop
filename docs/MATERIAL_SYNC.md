# 固定创作资料随书同步

更新：2026-10-27。beta.6包含045容量提示和新增历史前的名额保护，沿用beta.2以来的固定资料同步与后续历史找回/ZIP能力；beta.5及更早版本没有045改动，beta.1不含固定资料随书同步。实际包验证见[beta.6验收](BETA6_ACCEPTANCE.md)，安装包状态以同版Release为准。

## 使用

打开一本小说，在写作空间左侧选择“固定资料同步…”，启用并点击“立即同步”。以后应用启动载入书架、打开本书、保存并退出时自动核对。本机需要先保存正文及各页修改，运行中的模型任务会阻止换入资料。

正式资料在本机应用数据目录的固定 `创作资料/<projectId>/`，Windows默认 `%APPDATA%/novel-writer/创作资料/<projectId>/`。beta.2将其移出安装目录以保护升级；旧版资料先校验备份、仅向空目标迁移，已有差异时停止，见[安装资料保护](INSTALLER_SAFETY.md)。本书 `小说资料/创作资料同步/版本/<UUID>/` 是传输镜像，包含 `files/` 和最后发布的 `manifest.json`；应连同小说文件夹完整交接。另一设备未明确停用过本书同步时，收到完整镜像后会自动启用核对，载入其自己的固定目录；此前手动停用过则需重新启用。停用只作用于本机，不删除资料或书内版本。

外部 NAS/网盘客户端负责传输小说目录。此功能并不登录飞牛、百度或迅雷，也无法报告官方客户端的远端同步进度。两台 Windows 轮流写作；换设备前先保存退出，再等待客户端传输完成。可手动传输完整小说目录，不能只传 DOCX 而遗漏“小说资料”。

## 内容与边界

- 镜像仅复制该小说固定资料根内文件，包括人物卡 Markdown、头像/导入原卡、创作笔记、文风、大纲与故事记忆及其历史。已保存的筹备文件内仍有“未确认草稿”栏目，按原样保留，不会转换为已确认大纲或世界观。
- 正文、封面、分集、参考文本、讨论、世界书、正则和六类结构化资料位于小说目录中，本身随书传输，不再复制进固定资料镜像。
- 不镜像 AppData、API 密钥、模型连接、AI 任务、本机用量账本、UI 临时草稿和可重建索引。固定根出现数据库、账户配置或临时文件会停止同步，不能把用户数据目录当成固定资料根。
- 没有文件监听器或周期后台推送。应用保持打开时收到另一端更新，需要保存当前修改后点击“立即同步”，或重新打开本书。
- 单文件上限32 MiB，单快照256 MiB、最多10,000条目；书内传输根和本机替换前归档根各最多1,000个占用条目，未完成目录也占名额。045在新增前检查名额，800开始预警，满额拒绝需要新增该侧历史的操作；无改动核对、纯推送/无需新版本的拉取按实际需要判断。[历史浏览、找回、单版本ZIP与ZIP导入](MATERIAL_HISTORY.md)已提供，ZIP不释放名额。完整DAG批量归档/清理尚未实现，不要删除父版本绕过限制。

## 冲突与原稿保护

本机保存按小说隔离的共同基线哈希，比较“本机 / 传输版本 / 上次基线”。不同文件的独立修改可合并，同一路径双方修改、删除与修改相遇时必须选择。本机无基线时，已有不同内容也判冲突，不按时间戳决胜。未解决前不改双方正式内容。

版本是不可变完整快照，没有可覆盖的 head 文件。父版本形成 DAG；多个叶子表示并行修改，作者先选择一个完整远端版本，再逐文件处理与本机的冲突。未选分支的独有内容不自动混合，仍留在历史中。合并版本引用全部叶子。选择请求携带预览指纹，期间有变化必须刷新。

换入前排空主进程文件操作，阻止新操作进入并检查后台 AI。暂存完整目录、重新校验原稿和远端清单后，将原固定目录整体归档至应用 `创作资料/同步历史/<projectId>/<UUID>/`，再换入。删除状态也保留旧版；换入记录支持下次启动恢复中断。操作失败时保留原件/历史/暂存，不能承诺跨机器分布式事务。磁盘在最终校验之后仍可能被外部程序修改，因此保留归档和再次核对是必要保护。

未知schema、错书ID、非法路径、大小写/Unicode等价路径、链接、损坏清单、缺父版本或所选文件哈希不符均阻止同步。无manifest的未完成目录不作为已完成版本，但仍计入根目录容量；已发布但损坏的manifest不回退覆盖。传输顺序不保证完整，遇缺文件时等待外部客户端完成后刷新。

## 验证

`tests/material-sync.test.ts`覆盖首次发布/新端拉取、双向独立合并、同文件和删除冲突、过期指纹、并行分支、部分上传/损坏/非法路径/未知版本、源变化及换入中断恢复。`operation-gate.test.ts`覆盖在途读取排空、交换互斥与异常释放。

`tests/material-sync-desktop.ts`实际启动 Electron，用A/B两个独立配置顺序读写同一临时虚构目录，验证DOCX字节保留、卡/世界观往返、保存退出发布、dirty阻止、冲突留窗、过期选择拒绝、明确采纳和两书隔离。这是本机隔离配置验证；没有把它写成真实第二台设备或官方客户端双向传输验收。按用户最新要求，不进行真实断网测试。
