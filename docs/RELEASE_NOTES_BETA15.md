# 星序 starwriting 0.1.1-beta.15

星序（starwriting）是原“小说编写器”的新显示名称。本版仍是 Windows x64 预发布测试版，不是稳定正式版；安装包未进行代码签名，Windows 可能显示安全提示。

## 本版主要变化

- 用星芒与轨道图形作为应用标志，界面使用新名称并显示实际应用版本。
- 简化顶部导航，将部分功能收纳到“更多功能”；保留红色“保存并退出”。书架、写作、角色和模型设置等页面调整了视觉层次和窄窗口布局。
- 模型设置和写作页面采用离线原创图形区分部分接口来源；图形并非服务商官方商标，自定义和代理地址使用通用标识。
- 继承 beta.14 的正文保存保护、固定资料历史管理、TXT 空行处理和受限 Word 保真副本编辑。导入角色卡的未确认草稿如在重启后失去临时数据，需要重新选择原文件。

## 使用和升级

安装前请备份小说目录和本机创作资料，并关闭本程序及可能同时编辑同一章的其他程序。多台设备轮流写作时，先确认前一台保存且文件同步完成，再在另一台打开。

这是测试版本：真实 Word/WPS 的全部格式兼容、真实 NSIS 覆盖安装、跨设备云端及所有模型服务商的联调仍待验证。模型 API 由使用者自行配置，调用可能计费。NAS 和网盘账户直连暂未开放；用户自行配置的同步文件夹由相应客户端负责传输。

安装包与源码不包含作者的小说、NAS 账户或 API 密钥。安装器和源码的校验值以本次发布的 SHA256 清单为准。完整功能与测试边界见同版验收说明。
