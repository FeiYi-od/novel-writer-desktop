# 星序 starwriting beta.16 测试与升级注意事项

本版是未签名的 Windows x64 预发布测试版。安装或升级前，请先备份小说目录和本机创作资料，关闭本应用及可能同时写入同一章节的其他程序。首次验证请使用独立虚构小说目录。

1. 检查界面名称、版本号与页眉/写作欢迎页图标；Windows 部分旧程序或快捷方式名称为兼容保留。
2. 新建虚构小说，检查默认 DOCX、宋体五号、两个可复制的全角空格，保存重开后核对内容。
3. 检查资料转换草稿与确认保存流程；未经确认的草稿不能成为正式设定。
4. 检查外部编辑冲突和固定资料历史；历史还原前先确认范围与备份。
5. 多台设备需轮流编辑并确认前一台同步完成。模型服务由使用者自行配置，调用可能计费。

真实 NSIS 覆盖安装、真实 Word/WPS 全格式、两机云端及全部模型服务商尚未验收。NAS/网盘账户直连暂未开放；发现异常先保留原稿和恢复目录。
