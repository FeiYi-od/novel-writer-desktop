# 星序 starwriting 0.1.1-beta.17

Windows x64 整合预发布版，包含此前的星序界面、应用图标和本地创作功能。本版源码与安装包使用同一版本；安装包自带运行环境，无需安装 Node.js 或下载源码。

## 本版修复与优化

- 安装界面、桌面/开始菜单快捷方式及系统卸载列表改用“星序 starwriting”。内部程序文件名仍为“小说编写器.exe”，应用 ID 与本机数据身份不变。
- 修复便携打包漏收应用图标的问题，图标原样进入输出目录和 ZIP，仍拒绝未知资源和已有输出目录。
- 优化“检查更新”窗口的版本层次、输入区域、窄屏布局和键盘焦点。检查仍由作者主动点击，令牌仅供本次请求；下载在浏览器完成。
- 安装升级时，若旧名称和新名称快捷方式同时存在，先停止并提示处理，避免重命名失败后继续打开旧程序；不自动删除冲突链接。

## 下载与使用

下载 `starwriting-0.1.1-beta.17-x64.exe` 安装。`starwriting-0.1.1-beta.17-source.zip` 供开发与许可核对，普通使用无需下载。校验值见同页 `SHA256SUMS.txt`，测试与升级边界见 `ACCEPTANCE.md`。

默认正文 DOCX、宋体五号、两个可复制全角空格；人物、世界观等固定 Markdown 资料继续按小说隔离。安装包不含作者小说、个人 NAS 配置或 API 密钥。NAS/网盘账户直连暂未开放。

安装包未签名，仍属测试版。真实 NSIS 覆盖安装、真实 Word/WPS 全格式及所有外部模型/设备联调尚未全部验收。安装前请保存退出并备份小说和本机创作资料。
