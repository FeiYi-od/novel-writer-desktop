# 星序 starwriting 0.1.1-beta.16

这是 Windows x64 预发布测试版，安装包未签名。星序（starwriting）是原“小说编写器”的新显示名称。

## 本版主要变化

- 统一应用内品牌图形：页眉和写作欢迎页使用与桌面应用同源的星芒轨道图标。
- 调整资料转换页面的视觉层次、输入区域和窄窗口布局，保留原有编辑、确认及保存流程。
- 更新安装安全提示中的显示名称。为了保护旧版升级与资料路径，安装身份、程序文件名和快捷方式等兼容标识仍沿用原名称，Windows 部分位置可能仍显示“小说编写器”。

安装前请备份小说目录及本机创作资料，关闭本应用和可能同时编辑同一章节的程序；多设备请轮流写作并确认同步完成。真实覆盖安装、真实 Word/WPS 全格式兼容、跨设备云端及全部模型服务商联调仍待验收。NAS 和网盘账户直连暂未开放。

安装器和源码的校验值以发布附件中的 SHA256 清单为准；源码与许可一同提供。完整测试边界见同版验收说明。
