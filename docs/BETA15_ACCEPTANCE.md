# 星序 starwriting beta.15 测试和升级注意事项

本版是未签名的 Windows x64 预发布测试版。首次使用或升级前，请备份小说和本机创作资料；关闭本程序及可能同时写入同一小说的 Word、WPS 和其他编辑器。首次验证请使用独立的虚构测试目录。

1. 确认界面名称、图标与版本号，检查书架及“更多功能”菜单可以访问所需功能。
2. 新建虚构小说，验证默认 DOCX、宋体五号和段首两个可复制的全角空格；保存后重新打开，检查内容是否一致。
3. 分别检查 TXT 空行、外部文件改动时的冲突提示，以及同一本小说的固定资料；历史整套还原前确认范围并保留备份。
4. 人物卡未确认导入草稿重启后若提示临时数据失效，重新选择原文件后核对字段、头像与扩展，再决定是否确认。
5. 使用两台设备时轮流编辑：第一台保存并确认同步完成后，第二台再打开同一本书。不要同时写同一章节。网络服务与模型额度由使用者自行配置。

未执行真实覆盖安装验收和所有 Word/WPS 格式兼容验收；本版不是完整 Word 编辑器或完整酒馆插件运行环境。NAS 和网盘账户直连暂未开放。出现异常时保留原稿和恢复目录，先复制备份再记录重现步骤。
