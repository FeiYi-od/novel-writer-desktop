# 小说编写器 0.1.1 Beta 5

Windows x64测试版，合并正则隔离预览和社区JSON导入两批改动。beta.4及旧附件保留。

## 本版改动

- **正则预览不会占住主进程**：支持的宏和正则在可终止Worker内计算，默认最多3秒，可取消；超时、取消、来源变化或失败不返回部分结果，结束后可重新预览。
- **社区JSON导入**：兼容酒馆单条对象、批量数组和`scripts`包装，导入后显示识别格式、原始JSON路径/SHA及未参与预览的字段。完整原始字节和扩展字段独立保留，旧活动脚本先备份，未知目标版本/错书/外变拒绝。
- **多书与退出保护**：每次请求固定小说、请求ID和来源版本；取消可绕过排队的资料同步，迟到结果不会落入其他书。计算或导入期间的重复操作、关闭和保存退出受控；退出会话不接受新预览或导入。
- **预览界面**：宽文本区、双栏结果、原件路径复制、纯文本兼容报告及超长示例提示。预览不改正文、不把社区数据确认为正史、不调用模型或执行上游JavaScript。

正文仍默认DOCX、宋体五号10.5磅，段首为两个可复制的真实全角空格。沿用beta.4的历史ZIP导入及保真副本编辑能力，详见[既有验收指南](BETA4_ACCEPTANCE.md)。完整酒馆插件生命周期、Word完整排版和网盘账户直连仍未实现。

## 安装与数据

两台电脑先保存退出、保留整书及创作资料备份，再安装同一版本；不要先卸载旧版或删除“创作资料”。模型连接由本机独立管理，不复制整个AppData给另一台。安装包及源码不包含作者的NAS信息、账户、密钥或小说。测试包未签名，下载时核对同版`SHA256SUMS.txt`。
